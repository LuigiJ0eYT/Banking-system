# Bank Account Simulator

This is a C# project that I made to increase my knowledge of using Object Oriented Languages and C# during my work placement. It can simulate simple bank account operations such as deposits, withdrawals and balance tracking

## Features
- Deposit money
- Withdraw money
- View transaction history

## How to Run
1. Clone the repository:
   git clone [https://github.com/your-username/your-repo.git](https://github.com/LuigiJ0eYT/Banking-system)

2. Open the solution file in Visual Studio:
   BankAccountSimulator.sln

3. Build the solution (Ctrl + Shift + B)

4. Run the program (F5)
